# create_moodle_course_using_youtube_video_series

moodle_course_creator.py program can be used to create a Moodle course backup file which can be used to restore a Moodle course.
The program used a videowatch plugin to add a youtube video watch activity to each sections.

If you want to use other activity plugin rather than videowatch, replace videowatch with your video plugin activity.

The youtube video series URL should be entered in source.txt file along with starting video series index and final index.
